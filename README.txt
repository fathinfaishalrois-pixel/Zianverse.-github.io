24.10 — Zian's Multiverse
=========================

THIS ZIP CONTAINS
- index.html: regular static website
- assets/: all four original photos

EASIEST PHONE-ONLY OPTION
Download the separate single-file build named “zian_multiverse_single_index.html”. It includes the site and all four photos in one HTML file, so you only upload one file and do not need to manage an assets folder. When uploading to GitHub, name it index.html (or upload and rename it in the GitHub web interface).

GITHUB PAGES DEPLOYMENT FROM ANDROID
1. Open github.com in Chrome, sign in, and create a new PUBLIC repository named zian-multiverse.
2. Upload the single-file HTML and name it index.html. Commit the change.
3. In the repository, open Settings → Pages.
4. Under “Build and deployment”, choose “Deploy from a branch”, select “main” and “/ (root)”, then Save.
5. Wait for the published URL shown in Settings → Pages, then open it on your phone.

ALTERNATIVE USING THIS ZIP
1. Download and extract the ZIP using your phone's Files app.
2. Upload index.html and the complete assets/ folder to a static host such as Netlify or Cloudflare Pages. Keep assets next to index.html.
3. If the mobile browser cannot select a folder, use the single-file option above.

FEATURES
- Birthday gate accepts exactly 24 / 10 / 2008.
- Indonesian + English copy throughout.
- Original four photos preserved unchanged.
- Responsive mobile-first layout, scrapbook layers, reveal animations, photo lightbox, interactive wish cards, petal interaction.
- Optional ambient music and synthesized sound effects. Sound only starts after an explicit tap, following mobile browser autoplay rules. Sound can be toggled off.
- CSS animations with reduced-motion support and no external libraries or build step.
- No external fonts/CDNs are required.

NOTE
The gate is a playful client-side birthday gate, not secure authentication. Its date can be discovered by inspecting the page source. The site is static and requires no server or backend.
